# Reproducing the main results

From the repository root, first run `cd reproduction` in your terminal.
All commands and output paths below are relative to that directory.
Results, fitted objects, and RDS files
are not distributed. Run the analyses before collecting results and drawing
figures. Neither package installation nor the default plan starts simulations.

## 1. Figures and tables after running the analyses

Install `ggplot2` and `patchwork`, then run:

```sh
Rscript scripts/render_paper_results.R results/paper_reproduction output/reproduced
```

This creates Figures 3–6 and numerical-result tables from your locally collected
simulation and application outputs. Complete sections 2 and 3 first.
The introductory numerical illustration is separately generated by:

```sh
Rscript scripts/plot_paper_binary_illustration.R
```

## 2. Rerun numerical experiments

Install the [fitting dependencies](installation.md) and
[official comparator software](comparators.md). Display the analysis plan:

```sh
Rscript scripts/paper.R plan
```

Choose an analysis: `continuous_bounds`, `binary_bounds`,
`continuous_comparators`, `binary_comparators`, or `compatibility`.
Each automatically includes the settings reported in the main text.
There is no need to select separate sensitivity-value or sample-size batches.
The plan lists the task IDs to run for each analysis.

Generate the population targets needed by the endpoint studies first (numerical
integration, potentially expensive, but no simulated datasets):

```sh
Rscript scripts/paper.R experiment continuous_bounds targets
Rscript scripts/paper.R experiment binary_bounds targets
Rscript scripts/compute_paper_targets.R
```

For each analysis, run preflight, all task IDs shown by the plan, then collection:

```sh
Rscript scripts/paper.R experiment continuous_bounds preflight
Rscript scripts/paper.R experiment continuous_bounds task 1
# Run every remaining task ID shown by the plan with your chosen scheduler.
Rscript scripts/paper.R experiment continuous_bounds collect
```

Use `compatibility` in the same commands to run all main-text compatibility
experiments, without selecting sample sizes separately.

These commands can be expensive. They do not submit jobs automatically.
Workspaces and checkpoints are created locally under `results/work/`.
Source or configuration changes cannot silently reuse existing checkpoints.
Use fresh checkpoints; do not import historical cluster signatures. Original
drivers run only RKHS, the fixed spline threshold class, and X-adjusted
competitors. Supplementary learner/class comparisons are not run. Seeds,
original outcome-specific tuning, and estimating
equations are preserved. Do not replace them with newer package defaults and
call the result an exact reproduction.

After collecting all five analyses:

```sh
Rscript scripts/collect_paper_results.R results/paper_reproduction
Rscript scripts/render_paper_results.R results/paper_reproduction output/reproduced
```

Collection refuses missing/failed main-result replications. Incompatible
continuous IV-MSM setting-4 values have no population coverage target; only
the value 2 is shown diagnostically in the boxplots. Coverage uses each method's
own numerical population targets, generated in `results/population_targets.rds`.
These are numerical integration approximations, not causal ATE
truths or formal support-wide compatibility certificates.

## 3. Oregon Health Insurance Experiment

Obtain the [authorized input data](../reproduction/data/README.md). Only the administrative
emergency-department application is included. Run:

```sh
Rscript scripts/prepare_ohie_application_data.R
Rscript scripts/run_ohie_updated_fixed_median_application.R
Rscript scripts/run_ohie_rkhs_bands.R data/ohie_application.rds \
  results/ohie_application/ohie_ed_expanded_gam_hal_gamma_fixed_median_minimum_rank10_r2_lambda12_20_v1/nuisance_checkpoint.rds \
  results/ohie_rkhs_bands
Rscript scripts/run_ohie_comparator_confidence_bands.R
Rscript scripts/run_ohie_updated_gamma_compatibility.R
Rscript scripts/run_ohie_balke_pearl.R
Rscript scripts/run_ohie_aipw_benchmark.R
```

The comparator driver fits only the X-adjusted main-text comparators. It does
not need old comparator checkpoints. The compatibility runner retains the
original calibration grid; the collector extracts values 1, 1.1, and 1.2.
The IV-only reference reuses fitted nuisances. The AIPW benchmark retains its
original probability-nuisance recipe; it is not an IV-identified causal estimate.

Then add the application aggregates to the collected simulation results:

```sh
Rscript scripts/collect_ohie_results.R results/paper_reproduction
Rscript scripts/render_paper_results.R results/paper_reproduction output/reproduced
```

The application uses 22,170 household-index adults. It requires the data provider's
access terms and substantial computation. Keep raw data, fitted nuisance caches,
and person-level scores private. Never upload a working results directory.

## Verification without new experiments

```sh
Rscript scripts/public/run_smoke_tests.R
Rscript tests/test_paper_collection.R
Rscript tests/test_experiment_configuration.R
Rscript scripts/check_comparator_dependencies.R
```

Compatibility bookkeeping tests can be run with `Rscript scripts/tests.R` from
`results/work/compatibility_12000/`, after running
`Rscript scripts/prepare_experiments.R` from `reproduction/`. Estimator calls in those tests are
mocked; small generator-parity and calibration fixtures are not Monte Carlo
studies. Package tests and plotting saved aggregates do not establish statistical
assumptions or replace a complete rerun. Different software versions can change
random fits. No original fitted results are included in this repository.
